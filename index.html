SQL · PHP · Laravel · CSS · JS

Kas es esmu

Esmu programmēšanas studiju 3. kursa students ar vidēja līmeņa zināšanām vairākās tehnoloģijās, taču visstiprāk jūtos SQL datubāzu darbā un PHP backend izstrādē, tostarp strādājot ar Laravel ietvaru.

Papildus attīstu prasmes CSS un JavaScript jomā, lai spētu strādāt arī ar lietotnes vizuālo pusi un labāk saprastu pilnu izstrādes procesu. Īpaši augstu vērtēju darbu ar jau esošu kodu - atkļūdošanu, dokumentēšanu un ilgtermiņa uzturēšanu, nevis tikai jaunu funkciju rakstīšanu no nulles.

Strādāju gan latviešu, gan angļu valodā un ikdienas darbā izmantoju Git un GitHub versiju kontrolei un sadarbībai.
